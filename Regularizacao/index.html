Regularização em Regressão Linear: L1 (Lasso) vs L2 (Ridge)

Polinômio de alto grau treinado em um subconjunto central dos dados — veja o modelo explodir nos extremos (overfitting) e como L1/L2 controlam a complexidade.

1) Equações

Features Polinomiais (normalizadas)

x̂ = 2·(x − xₘᵢₙ) / (xₘₐₓ − xₘᵢₙ) − 1 → x̂ ∈ [−1, 1]
φ(x) = [1, x̂, x̂², x̂³, ..., x̂ᵈ]
ŷ = θᵀφ(x) = θ₀ + θ₁x̂ + θ₂x̂² + ... + θᵈx̂ᵈ
J_MSE = (1/2m) Σᵢ (ŷᵢ − yᵢ)²

Funções de Custo com Regularização

Ridge (L2): J = J_MSE + λ Σⱼ₌₁ᵈ θⱼ²
Lasso (L1): J = J_MSE + λ Σⱼ₌₁ᵈ |θⱼ|
∂J/∂θ₀ = (1/m) Σ(ŷᵢ − yᵢ) [sem reg.]
∂J/∂θⱼ = (1/m) Σ(ŷᵢ−yᵢ)φⱼ + { 2λθⱼ (L2) | λ·sgn(θⱼ) (L1) }
θⱼ ← θⱼ − α · ∂J/∂θⱼ [L1 usa thresholding proximal]

2) Controles

⚠ Os coeficientes divergiram (NaN ou Inf). Reduza α e clique em Resetar.

💡 Experimento 1 — Overfitting: Com "Nenhuma" regularização, clique Solução Exata. O polinômio interpola os 10 pontos de treino (x ∈ [−2, 2]) mas explode nos extremos onde estão os 20 pontos de teste (x ∈ [−3, 3]) — MSE Treino ≈ 0, MSE Teste altíssimo.
Experimento 2 — Regularização: Clique Resetar, selecione L2 (Ridge), clique Solução Exata. A curva suaviza drasticamente — Ridge penaliza coeficientes grandes que causam a explosão.
Experimento 3 — Esparsidade (L1): Clique Resetar, selecione L1 (Lasso), clique Rodar N passos repetidamente. Observe os coeficientes zerando gradualmente — L1 produz modelos esparsos.
Experimento 4 — U-shape: Com "Nenhuma" e partindo de θ=0, clique Rodar N passos várias vezes. O MSE Teste primeiro cai (aprendendo o sinal) depois sobe (ajustando ruído).
