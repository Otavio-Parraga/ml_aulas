KNN — K Vizinhos Mais Próximos

Ajuste K, escolha a métrica de distância e clique no canvas para classificar novos pontos interativamente. Observe como a fronteira de decisão muda com K — pequeno K tende ao overfitting, grande K ao underfitting.

1) Conceitos-chave

Algoritmo KNN

Para cada ponto de consulta x_q:
d(x_q, x_i) para todo x_i no treino
Selecionar os K vizinhos mais próximos N_K(x_q)
ŷ = moda { y_i : x_i ∈ N_K(x_q) }

Métricas de Distância & Efeito de K

Euclidiana: d(a,b) = √( Σ (aᵢ − bᵢ)² )
Manhattan: d(a,b) = Σ |aᵢ − bᵢ|
K pequeno → fronteira complexa → overfitting
K grande → fronteira suave → underfitting
