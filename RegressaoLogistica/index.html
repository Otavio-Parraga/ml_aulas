Regressao Logistica: Gradiente Descendente (iterativo)

Exemplo visual e passo a passo de regressao logistica simples com uma feature. Usa apenas gradiente descendente — sem equacao normal.

1) Equacoes da Regressao Logistica

z_i = theta0 + theta1 * x_i
h_theta(x_i) = sigmoid(z_i) = 1 / (1 + e^(-z_i))
J(theta) = -(1/m) * SUM[ y_i*log(h_i) + (1-y_i)*log(1-h_i) ]
dJ/dtheta0 = (1/m) * SUM( h_i - y_i )
dJ/dtheta1 = (1/m) * SUM( (h_i - y_i) * x_i )
theta_j := theta_j - alpha * dJ/dtheta_j

2) Controles do Exemplo

O slider e o campo de iteracao permitem navegar no historico do gradiente descendente. Diferente da regressao linear, nao existe equacao normal para regressao logistica — o gradiente descendente e o caminho.
