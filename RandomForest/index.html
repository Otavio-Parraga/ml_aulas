Random Forest — Construção Árvore por Árvore

Adicione uma árvore por vez e observe como a acurácia do ensemble e o OOB error evoluem. Explore também a importância de cada feature acumulada pela floresta.

1) Conceitos-chave

Bootstrap & Bagging

Bootstrap sample: n amostras com reposição de D
Out-of-Bag (OOB) ≈ 36,8 % dos dados ficam fora
OOB Error = 1 − (acertos OOB / total OOB)
ŷ_ensemble = moda( ŷ_1, ŷ_2, ..., ŷ_T )

Importância de Feature (Mean Decrease Impurity)

Gini(t) = 1 − Σ p_k²
ΔImpurity(f,t) = impurity(t) − w_L·impurity(t_L) − w_R·impurity(t_R)
FI(f) = (1/T) · Σ_t Σ_{nós com f} ΔImpurity(f,t)
FI normalizada: FI(f) / Σ FI(f')
