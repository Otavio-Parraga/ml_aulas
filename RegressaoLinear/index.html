Regressao Linear para Aula: Gradiente (iterativo) x Equacao Normal (fechada)

Exemplo visual e passo a passo focado apenas em regressao linear simples. Sem regressao logistica.

1) Equacoes da Regressao Linear

h_theta(x) = theta0 + theta1 * x
J(theta0, theta1) = (1 / (2m)) * SUM( h_theta(x_i) - y_i )^2
dJ/dtheta0 = (1/m) * SUM( h_theta(x_i) - y_i )
dJ/dtheta1 = (1/m) * SUM( (h_theta(x_i) - y_i) * x_i )
theta_j := theta_j - alpha * dJ/dtheta_j
theta = (X^T X)^(-1) X^T y
